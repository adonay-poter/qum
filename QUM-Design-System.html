Design
System

A film-festival microsite system for the QUM protocol app: mono everywhere, one spotlight orange, negative space as composition. Aligned with Design.md and production tokens in src/design-system/tokens.ts.

v1.0.0 30+ components WCAG AA target 8px base grid

01 · Principles

How we design

Five load-bearing principles. Break one and the brand reads as generic wellness UI.

01

One spotlight

Tertiary orange drives exactly one primary action per screen — plus reserved identity uses (ቁም, Halt Bar).

02

Flat & mono

IBM Plex Mono for UI copy. No gradients. Surfaces stack via value, not blur.

03

Festival grid

12 columns, 8px rhythm, hairline borders. Schedule-board clarity under stress.

04

Bilingual dignity

Amharic glyph in Bela Bereka / Noto Ethiopic — never reduced to decoration.

05

Calm under urge

Motion is purposeful (breath, halt, victory). Reduced motion respected.

14 · Patterns

Screen patterns

Auth stack

BilingualLockup (md, start-aligned) → h1 → body → form → single primary CTA → ghost link.

Wave flow

Full-bleed neutral bg, SessionTimer progress, phase title h1, verifier control, accent only on commit action.

Settings list

List items with chevron, secondary captions, no accent until destructive confirm.

Crisis support

Error semantic for urgency copy; hotline list — never orange decorative noise.

Loading analytics

HaltBarLoader centered + skeleton bars; aria-busy on parent.

15 · Guidance

Do & Don't

Do

  • Use tertiary for exactly one action per screen.
  • Let neutral carry composition — negative space is a feature.
  • Pair labels with inputs; expose errors to assistive tech.
  • Keep Amharic glyph in accent at lockup sizes only.
  • Mirror tokens from tokens.ts / tokens.json in Tailwind.

Don't

  • Introduce gradients — flat on purpose.
  • Mix tertiary with alternate accent colors.
  • Stack multiple pulsing urge CTAs.
  • Use rounded corners beyond lg (4px).
  • Ship decorative orange icons in lists.

17 · Dev guide

Implementation

Stack

React 18 + Vite + Tailwind. Import tokens from @/design-system/tokens. Identity from @/design-system/identity.

Tailwind mapping

colors: primary, secondary, tertiary, neutral, surface, on-primary
fontFamily: mono (IBM Plex Mono), bela (Bela Bereka)
spacing: qum-sm (8), qum-md (16), qum-lg (32)
fontSize: display, h1, body, label

Accent budget (enforced in review)

Per route: count elements with bg-tertiary / text-tertiary decorative use. Max one bg-tertiary button unless identity loader.
